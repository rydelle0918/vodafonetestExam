# PlaywrightExam

Minimal Playwright Test setup created programmatically.

Try it:

```powershell
cd C:\PlaywrightExam
npx playwright test
npx playwright show-report
npx playwright test part2.spec.ts --ui // run and shows with UI
```

Files added:
- `playwright.config.ts` - basic Playwright Test config.
- `tests/example.spec.ts` - sample test that checks example.com title.
